CineMax - Java (JDK 21)

Progetto di Morad, Ayman, Giovanni e Harman 

Istruzioni per l'esecuzione del progetto

Prerequisiti:
- Avere la JDK 21 installata nel computer, link di installazione https://www.oracle.com/java/technologies/downloads/#java21.
- Spostare il file `CineMax.jar` dentro la cartella `bin`, nella cartella root della progetto e avviarlo.
